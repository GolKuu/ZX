# Профилирование Circle Clash

Игра измеряет производительность прямо в каждом типе боя: локальном 1×1,
командном и онлайн. Метрики доступны в `window.__ZX_DIAGNOSTICS__`.

Чтобы увидеть компактный оверлей, запустите бой с `?perf=1` в адресе. Обычный
игрок оверлей не видит, поэтому HUD остаётся чистым.

## Что измеряется

- `fps` и `maxFrameMs` — среднее и худшее время кадра за последние 180 кадров;
- `cpuMs` — время симуляции и подготовки рендера на CPU;
- `gpuMs` — время GPU через `EXT_disjoint_timer_query_webgl2`, если браузер
  предоставляет расширение;
- `memoryMb` — занятая JS-память в браузерах с `performance.memory`;
- `drawCalls` — число вызовов WebGL за кадр;
- `liveObjects` и `objectDrift` — число объектов Phaser и его рост;
- `canvasCount` — защита от накопления canvas после повторного входа;
- `hitboxErrors` — расхождения визуальных атак с боевыми hitbox.

Значение `—` для GPU или памяти означает, что браузер не открыл соответствующий
низкоуровневый API. Это не подменяется приблизительным числом.

## Бюджеты сцены

| Метрика | Цель |
|---|---:|
| FPS | 60 |
| CPU | до 8 мс |
| GPU | до 8 мс |
| Draw calls | до 150 |
| Object drift после прогрева | 0 |
| Canvas | 1 |
| Ошибки hitbox | 0 |

Мультяшные частицы используют фиксированный пул из 36 объектов. Один удар
активирует не больше 17 базовых частиц плюс поправку на урон, а итог всегда
ограничен размером пула. Объекты переиспользуются и плавно исчезают без
создания нового массива игровых объектов на каждом попадании.
