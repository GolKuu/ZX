# Character quality gate

Минимальная итоговая оценка любого игрового персонажа: **97/100**.

Персонаж не получает статус production-ready, если независимая оценка ниже 97,
даже если сборка и игровые тесты проходят. Предыдущие оценки не округляются.

## Обязательные области

| Область | Минимум |
|---|---:|
| Визуальный дизайн и силуэт | 97 |
| Модели, спрайты и материалы | 97 |
| Анимации и transitions | 97 |
| Читаемость normals и specials | 97 |
| VFX, звук и camera presentation | 97 |
| Hitbox/hurtbox alignment | 97 |
| Gameplay, баланс и контригра | 97 |
| AI и matchup coverage | 97 |
| Стабильность и производительность | 97 |
| Итоговая оценка | **97** |

## Правило приёмки

- `97–100`: ACCEPTED.
- `0–96`: REJECTED, требуется новая итерация и повторный независимый аудит.
- Критический дефект, infinite pressure, placeholder-графика или сломанная
  регрессия всегда дают REJECTED независимо от среднего балла.
- Визуальная приёмка требует кадров neutral, attacks, defense, Rage/stance,
  Supers и Ultimate, а также проверки frame pacing.

## Текущий статус

Старые оценки 85/100 для Vorgh и 92/100 для Glitch больше не являются
production-оценками по новому правилу. Они переводятся в `REJECTED` до повторной
доработки и оценки не ниже 97. Персонажи без независимой оценки также считаются
`REJECTED`.
