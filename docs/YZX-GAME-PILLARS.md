# YZX — Game Pillars

## Концепция

YZX — быстрый научно-фантастический 2.5D-файтинг для игроков 12+, которым нужны короткие тактические матчи, понятная клавиатурная раскладка и заметно разные бойцы. Один сет длится примерно 4–7 минут; тренировочная сессия — 5–20 минут.

Игроки входят в Null Circle, чтобы остановить сигнал, стирающий память бойцов. Каждый персонаж представляет отдельный способ читать соперника: сценические ловушки MIM, пространственные сдвиги Glitch, управляемый риск Lucky, ярость Vorgh и бронированные захваты Titan.

## Шесть опор

1. Читаемое управление: WASD + J/K/I/L, направления зависят от стороны бойца.
2. Разные роли: у каждого бойца собственные нейтраль, давление, слабость и ресурс.
3. Физический импакт: anticipation, hit-stop, реакция цели и наказуемое восстановление.
4. Контролируемые механики: сила всегда имеет понятную стоимость и контригру.
5. Быстрый цикл обучения: пауза, список приёмов, безопасный сброс и быстрый рематч.
6. Ясная обратная связь: бойцы контрастнее арены, HUD не перекрывается, эффекты можно снизить.

## Цели игрока

- Сейчас: понять раскладку, выиграть раунд, освоить один надёжный маршрут.
- За сессию: пройти урок или главу, победить нового соперника, открыть вариант PvE-стиля.
- В долгую: освоить всех пяти бойцов и завершить историю без преимущества прогрессии в локальном Versus.

## Поток матча

Главное меню → режим → сложность (для AI) → боец P1 → соперник → арена → готовность/подтверждение → матч → результат → рематч, смена бойцов или меню.
