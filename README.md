# Circle Clash

Тактический браузерный файтинг про реакцию, дистанцию и чтение соперника. В составе
15 оригинальных существ с разными силуэтами, движением и визуальным языком атак.
Система «Темп» наказывает беспорядочное нажатие кнопок: перегруженный боец теряет
возможность атаковать и открывается для контрудара, а точные блоки и осмысленные
попадания возвращают контроль.

React отвечает за сайт и маршруты, Phaser — за арену, а независимая
`CombatSimulation` работает с фиксированным шагом 60 Гц.

Стек: **Vite + React + TypeScript + Phaser 3 + Supabase + Vercel**.

Режим `LOCAL_PVP` поддерживает двух игроков на одной клавиатуре, клавиатуру с геймпадом
или два разных геймпада. Подготовка матча находится на `/local-pvp`, переназначение
клавиш — на `/controls`; бой нельзя запустить с конфликтующей или неполной конфигурацией.
Боевая сцена занимает весь viewport, а её hitbox/hurtbox, кадровые атаки, урон, блок,
энергия и комбо рассчитываются детерминированно внутри независимой симуляции.
Все бойцы и атаки рисуются оригинальной процедурной графикой без заимствованных
моделей. Воздушное управление позволяет перепрыгнуть соперника и сменить сторону,
а шкала темпа превращает бой в чередование разведки, защиты и наказания ошибок.
На `/auth` доступны подтверждаемая email-регистрация, вход по паролю, восстановление доступа
и гостевой режим. На `/profile` хранятся публичная карточка бойца, статистика, достижения
и приватно синхронизируемые игровые настройки.
Стандартная схема управления использует восемь назначаемых действий: движение,
прыжок, три вида атаки, защиту и паузу. Захват, суперприём, выход из комбо,
возврат инерции и низкая защита распознаются из сочетаний основных кнопок.
